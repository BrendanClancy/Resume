# Brendan Clancy – Personal website

**Live site:** https://brendanclancy.github.io/resume/

A one-page website for recruiters and hiring managers, showing my experience, projects and skills as a Senior Business Analyst in cards and payments.

## What's on the site

- **Experience:** roles from 1986 to today, across banks, a fintech and a payments processor in eight countries
- **Projects:** selected programmes, filterable by payments, cards and schemes, fraud and AML, and migrations
- **Skills and tools:** grouped by area, with a search box
- **How I work:** AI use as a business analyst, plus agile and SAFe practice
- **Résumé download** and a link to my LinkedIn profile

## Hosting

The site is static, so it needs no build step or server. It is hosted free on GitHub Pages from the `resume` repository, served from the `main` branch, root folder.

## Updating the site

1. Edit `index.html`.
2. Upload the new version to this repository, using the same file name so it replaces the old one.
3. GitHub Pages republishes the site within a minute or two.

To change contact buttons, edit the `CONTACT` line near the bottom of `index.html`. Adding an email address there makes an "Email me" button appear.

## Notes

- The page loads two fonts (Bricolage Grotesque and Figtree) from Google Fonts. If they can't load, it falls back to the system fonts.
- It follows the visitor's light or dark mode setting and works on phones.
